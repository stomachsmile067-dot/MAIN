## 🔧 HOW TO DOWNLOAD (Choose one method)

### Method 1: 4K Video Downloader (Easiest — RECOMMENDED)
- Download: https://www.4kdownload.com/
- Steps:
  1. Copy YouTube video URL
  2. Open 4K Video Downloader
  3. Click "Paste Link"
  4. Choose quality (1080p MP4)
  5. Click "Download"
- ✅ Pros: Easy, no ads
- ❌ Cons: Free version has daily limit (3 downloads)

### Method 2: yt-dlp (Advanced — no limits)
- Download: https://github.com/yt-dlp/yt-dlp
- Command:
```
yt-dlp -f "best[height<=1080]" "YOUTUBE_URL"
```
- ✅ Pros: No limits, very fast
- ❌ Cons: Need basic command line knowledge

### Method 3: Online (Quickest)
- y2mate.com
- ssyoutube.com
- savefrom.net
- ✅ Pros: No install needed
- ❌ Cons: Ads, slower, quality limited

## 📥 DOWNLOAD COMMANDS (yt-dlp)

If using yt-dlp, here's the command for batch download:

```bash
# Single video
yt-dlp -f "best[height<=1080]" "YOUTUBE_URL"

# Best quality
yt-dlp -f "best" "YOUTUBE_URL"

# Specific format (mp4)
yt-dlp -f "best[ext=mp4]" "YOUTUBE_URL"

# Audio only
yt-dlp -x --audio-format mp3 "YOUTUBE_URL"
```

For batch download (multiple URLs in a text file):
```bash
yt-dlp -a urls.txt -f "best[height<=1080]"
```
