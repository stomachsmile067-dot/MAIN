## 🎬 THE COMPLETE WORKFLOW (Step by Step)

### 📅 DAY 1: PREP (2-3 hours)

#### Step 1.1: Folder Setup (10 min) — **PR + AE prep**
```
Create these folders:
📁 SPEED_VIDEO/
├── 📁 01_PREMIERE_PROJECT/         (Premiere .prproj)
├── 📁 02_SOURCE_VIDEO/
│   ├── 📁 Speed_Clips/             (downloaded Speed clips)
│   ├── 📁 Free_Footage/            (Pexels, Pixabay B-roll)
│   ├── 📁 AE_Exports/              (rendered AE videos)
│   └── 📁 Audio/                   (music + SFX)
├── 📁 03_AFTER_EFFECTS/
│   ├── 📁 AE_Project/              (AE .aep files)
│   └── 📁 AE_Assets/               (logos + fonts)
├── 📁 04_FINAL/                    (final video export)
└── 📄 SCRIPT.md                    (your Saudi script)
```

#### Step 1.2: Create Premiere Project (5 min) — **PR**
```
1. Open Premiere Pro 2026
2. File → New → Project
3. Name: "Speed_Video_Final"
4. Location: 01_PREMIERE_PROJECT/
5. Settings (very important!):
   - Resolution: 1920x1080
   - Frame rate: 30 fps
   - Audio: 48kHz, Stereo
6. Click OK
```

#### Step 1.3: Import All Footage (30 min) — **PR**
```
File → Import → Select all files in:
- 02_SOURCE_VIDEO/Speed_Clips/
- 02_SOURCE_VIDEO/Free_Footage/
- 02_SOURCE_VIDEO/Audio/
```

#### Step 1.4: Organize in Premiere (15 min) — **PR**
```
Create bins (folders) in Project panel:
📁 01_Audio
   ├── Voiceover
   ├── Music
   └── SFX
📁 02_Speed_Clips
   ├── Hook

#### Step 1.5: Create Timeline Sequence (5 min) — **PR**
```
1. Right-click in Project panel
2. New Item → Sequence
3. Name: "Speed_Main_Video"
4. Settings: Match your project (1080p, 30fps)
5. Drag to timeline
```

#### Step 1.6: Setup Timeline Tracks (5 min) — **PR
```
Your timeline should have:
V1: Main video (Speed clips or main visual)

V5: AE imports (when ready)

### 📅 DAY 3: AFTER EFFECTS COMPOSITIONS (3-4 hours)

#### ⭐ AE COMP 1: Hook Title Card "بس ما أحد يعرف" (30 min)
**When in video:** 0:15 - 0:18 (3 sec)

**In After Effects 2024:**
```
1. Composition → New Composition
   - Name: "Hook_NoOneKnows"
   - Settings: 1920x1080, 30fps, 3 seconds

2. Add black solid background:
   - Layer → New → Solid
   - Color: Black
   - Click OK

3. Add text:
   - Type tool (T)
   - Click on canvas
   - Type: "بس ما أحد [pause] يعرف"
   - Font: Any bold Arabic font
   - Size: 100
   - Color: White
   - Center it

4. Animate:
   - Move playhead to 0:00
   - Click Stopwatch on "Opacity" (set to 0%)
   - Move playhead to 0:15
   - Set Opacity to 100%
   - Move playhead to 2:50
   - Set Opacity to 100%
   - Move playhead to 3:00
   - Set Opacity to 0%

5. Save: File → Save As → "Hook_NoOneKnows.aep" in AE_Project/

6. Export:
   - Composition → Add to Render Queue
   - Output Module: H.264
   - Output: AE_Exports/Hook_NoOneKnows.mp4
   - Click Render
```

### 📅 DAY 5: POLISH (3-4 hours)

#### Step 5.1: Fine Cut Timing (1 hour) — **PR**
```
Watch entire video:
- Pause at every cut
- Does the cut match the voice?
- If not, adjust by 1-2 frames
- Use , and . keys to move clip frame by frame
```

#### Step 5.2: Add Transitions (30 min) — **PR**
```
Add simple transitions between chapters:
- Cross dissolve (most common)
- Dip to black (between major chapters)
- Match cut (for similar scenes)

How:
- Effects panel → Video Transitions
- Drag to clips on V1
- Adjust duration in Effect Controls

DON'T add fancy transitions (whip, glitch, etc.) — too distracting
```

#### Step 5.3: Color Grade (1 hour) — **PR**
```
1. Select all clips on V1, V2
2. Lumetri Color panel
3. Apply a consistent look:

For cinematic look:
- Contrast: +15
- Highlights: -20
- Shadows: +10
- Saturation: -10
- Temperature: +5 (slightly warm)

For darker/moody:
- Contrast: +20
- Shadows: -20
- Saturation: -20
- Temperature: 0

4. Copy/paste this look to all clips (for consistency)
```

#### Step 5.4: Audio Mix (45 min) — **PR**
```
Audio levels (important!):
- Voiceover (A1): 0 dB (loudest)
- Music (A2): -15 to -20 dB (background)
- SFX (A3): -10 to -12 dB (noticeable)

How:
- Right-click on audio clip
- Audio Gain
- Adjust to target dB
```

#### Step 5.5: Add Captions (45 min) — **PR**
```
Method 1: Auto captions
1. Text → Captions → Create Captions from Transcript
2. Review and correct errors

Method 2: Manual
1. Text → Captions → Add Caption
2. Type each line
3. Style:
   - Font: Bold
   - Size: Large (for mobile)
   - Color: White
   - Background: Semi-transparent black
   - Position: Bottom center
```

#### Step 5.6: Final Review (30 min) — **PR**
```
Watch entire video 3 times:
- 1st time: Check cuts
- 2nd time: Check audio
- 3rd time: Check for any mistakes

Fix anything you see.
```

**Time: 3-4 hours** ✅

## 💡 PRO TIPS

1. **Save often** — Every 15 minutes (Ctrl+S)
2. **Backup daily** — Google Drive or external drive
3. **Use proxies** — If your PC is slow
4. **Color match** — B-roll should look like Speed's clips
5. **Audio first** — Cut video to audio, not the other way
6. **Less is more** — Don't overdo transitions/effects
7. **Watch on phone** — Most viewers watch on mobile
